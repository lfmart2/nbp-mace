# M0 relaxation benchmark artifacts

These files were generated by `src/eval_relaxations.py` from the private,
Git-ignored `data/m0_benchmark.xyz` dataset.

- `metrics.json`: environment, checkpoint hash, timing, and per-calculation metrics.
- `predictions.csv`: relative-energy predictions and per-frame force errors.
- `energy_trajectories.*`: DFT and zero-shot MACE energy trajectories.
- `error_summary.*`: energy and movable-force errors by source calculation.

Energy differences are referenced to the final structure within each source
calculation. No elemental shifts were fitted. Forces use the DFT labels
directly. QE/VASP and collinear/SOC groups are never pooled into one metric.
